# 천상 RPG — 온라인 전체 계정 관리·스킬북 업데이트

Windows용 2D 판타지 RPG 프로젝트입니다. 온라인 모드에서는 모든 플레이어가 하나의 Render API와 PostgreSQL 계정을 함께 사용합니다. 온라인 기능은 서버를 먼저 배포하고 `server_config.json`에 주소를 넣은 뒤에 활성화됩니다.

## 이번 업데이트

### 온라인 계정과 닉네임
- 회원가입 시 아이디, 닉네임, 비밀번호를 각각 입력합니다.
- 로그인은 아이디와 비밀번호로 합니다. 게임 화면에는 닉네임이 표시됩니다.
- 관리자 센터는 닉네임 또는 아이디로 서버의 계정을 검색할 수 있습니다.
- 서버에 연결된 모든 사용자의 계정 정보와 캐릭터 진행 데이터가 PostgreSQL에 저장됩니다.
- 온라인 비밀번호는 8글자 이상입니다.
- 기존 PC 로컬 계정은 `IMPORT_LOCAL_ACCOUNTS.bat`으로 온라인 서버에 이전할 수 있습니다. 비밀번호 원문이 아니라 기존 PBKDF2 해시를 옮깁니다.

> 온라인 계정/저장은 공유되지만, 이 버전은 실시간 협동·대전 멀티플레이가 아닙니다.

### 계정 관리 범위
- 온라인 서버에 연결되어 있으면 관리자 센터의 검색 대상은 이 PC의 로컬 계정이 아니라 서버 PostgreSQL에 등록된 모든 계정입니다.
- 검색어를 비우면 전체 계정을 불러오고, 닉네임 또는 아이디 일부를 입력하면 일치하는 모든 계정을 검색합니다. 화면은 8개씩 페이지로 나눠 표시합니다.
- 지역 이동 로직은 그대로 유지합니다. `ESC`를 눌러 메뉴를 열고 `천상 마을로`를 선택하면 돌아갈 수 있습니다.

### 스킬북 방식
- 새 계정은 배운 스킬 없이 시작합니다.
- 몬스터가 스킬북을 떨어뜨립니다. `B` 키로 스킬북 창을 열고 **배우기**를 눌러야 스킬을 배웁니다.
- 배운 전투 스킬은 `E`, `R`, `T`, `J`, `K` 키로 사용합니다.
- 기본 공격은 `SPACE`, 상호작용은 `F`입니다.
- 대표적인 스킬북: 풀숲의 별빛 파동, 피라미드 수호자의 이상한 스킬, 빛의 동굴 화염구, 메이플 사무라이의 별빛 돌진, 2세계의 마나 감지, 고대 수호자의 투명 감지.

### 2세계 / 마나 코어 / 최종 보스
1. 샌드 사막의 피라미드 수호자를 처치해 **수상한 종이**와 **이상한 스킬 스킬북**을 얻습니다.
2. `B` 키로 이상한 스킬 스킬북을 배웁니다.
3. 피라미드 입구에서 `F`를 눌러 2세계로 이동합니다. 수상한 종이와 배운 이상한 스킬이 모두 필요합니다.
4. 2세계 몬스터를 처치해 마나 감지 스킬북을 얻고 배웁니다.
5. `T` 키를 누르면 현재 MP를 전부 소모해 감지량으로 바뀝니다. 누적 10,000에 도달하면 마나 감지가 마나 순환으로 진화합니다.
6. 2세계의 고대 수호자에게서 투명 감지 스킬북을 얻고 배웁니다. 그 뒤에 숨겨진 최종 보스가 보입니다.

최종 보스: **화염의 다크 오브 파멸적인 천상의 투명 드레곤**

마나 코어는 마나석으로 성장합니다. 코어가 1레벨 오를 때마다 스탯 포인트 10개가 충전되며, 코어 레벨은 공격력을 크게 높입니다.

### 관리자 센터 (`F10`)
- 닉네임 / 아이디 검색
- 밴 / 언밴
- 점수, 레벨, 골드, 경험치 수정
- 스탯 포인트, 마나 코어 레벨 수정
- 힘, 체력, 마나, 민첩 수정
- 현재 HP / MP 수정
- 선택 계정 스킬북 지급 및 HP·MP 회복

관리자의 스킬 지급 기능도 스킬을 바로 배우게 하지 않고 스킬북을 가방에 넣어 줍니다. 대상 플레이어가 `B` 창에서 직접 배워야 합니다.

온라인 모드에서 이 기능들은 서버 전체 계정에 적용됩니다. 로컬 모드에서는 해당 PC에 저장된 계정만 관리합니다.

## 실행 방법
1. ZIP을 새 폴더에 압축 해제합니다.
2. `RUN_GAME.bat`을 실행합니다.
3. 처음 실행 시 `.venv`를 만들고 `pygame-ce`를 설치합니다.

## EXE 만들기
1. `RUN_GAME.bat`으로 게임 실행을 먼저 확인합니다.
2. `BUILD_EXE.bat`을 실행합니다.
3. `dist/CheonsangRPG.exe`가 생성됩니다. `server_config.json`도 EXE 옆에 복사됩니다.

## 온라인 서버 설정
`ONLINE_SERVER_SETUP.md`를 따라 GitHub 저장소에 프로젝트를 올리고 Render Blueprint로 API와 PostgreSQL을 배포합니다. 배포 뒤 `server_config.json`의 `api_url`에 Render 웹 서비스 기본 주소를 적어야 온라인 계정이 활성화됩니다.

Render 무료 웹 서비스는 15분간 요청이 없으면 잠들었다가 다음 요청에서 다시 시작할 수 있습니다. Render 무료 PostgreSQL은 생성 후 30일이 지나면 만료되므로 장기 계정 저장용으로 사용하면 안 됩니다. 장기 운영에는 만료되지 않는 데이터베이스 플랜이 필요합니다.

## 조작
- 이동: WASD 또는 방향키
- 기본 공격: `SPACE`
- 배운 스킬: `E` / `R` / `T` / `J` / `K`
- 상호작용: `F`
- 회복 물약: `L`
- 스킬북 / 배운 스킬: `B`
- 가방: `I`
- 지역 이동: `M`
- 캐릭터 스탯: `P`
- 마나 코어: `C`
- 관리자 센터: `F10` (관리자 계정)
- 메뉴 / 천상 마을 복귀: `ESC` → 메뉴에서 `천상 마을로` 선택

## 저장 데이터
- 로컬 모드: `%APPDATA%\CheonsangRPG\game.db`
- 온라인 모드: Render PostgreSQL
- 프로젝트 ZIP을 교체해도 로컬 저장 파일은 유지됩니다. 저장 파일 삭제는 계정과 진행 데이터를 지울 수 있으니 주의하세요.
