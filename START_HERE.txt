천상 RPG — 온라인 전체 계정 관리 / 스킬북 업데이트

1. 이 ZIP을 새 폴더에 압축 해제합니다.
2. RUN_GAME.bat을 실행합니다.
3. 회원가입할 때 아이디, 닉네임, 비밀번호를 입력합니다.
4. 로그인은 아이디와 비밀번호로 합니다.

스킬 진행:
- 처음에는 배운 스킬이 없습니다.
- 몬스터에게서 스킬북을 얻습니다.
- B 키 → 스킬북의 [배우기] 버튼을 누릅니다.
- 배운 스킬은 E / R / T / J / K 로 사용합니다.
- SPACE는 기본 공격, F는 상호작용입니다.

스탯/코어:
- P: 스탯
- C: 마나 코어
- T: 마나 감지 / 마나 순환 (스킬북을 배우고 난 뒤)

관리자:
- F10: 관리자 센터
- 온라인 서버 연결 시 닉네임 또는 아이디 일부로 서버의 전체 계정을 검색합니다.
- 계정 검색 결과는 8개씩 페이지로 나뉩니다.
- 관리자 스킬 지급은 스킬북을 주며, 대상 플레이어가 B키에서 배워야 합니다.

온라인 서버:
- `server_config.json`의 api_url이 비어 있으면 로컬 계정 모드입니다.
- 실제 온라인 사용을 위해서는 ONLINE_SERVER_SETUP.md를 따라 Render 서버를 먼저 배포해야 합니다.
- 기존 로컬 계정을 옮기려면 IMPORT_LOCAL_ACCOUNTS.bat을 실행합니다.

EXE 제작:
1. RUN_GAME.bat으로 먼저 실행을 확인합니다.
2. BUILD_EXE.bat을 실행합니다.
3. dist\CheonsangRPG.exe가 만들어집니다.

지역 이동:
- ESC를 눌러 메뉴를 엽니다.
- 메뉴에서 [천상 마을로]를 선택하면 마을로 돌아갑니다.
